# Process Overview

## 1. Application intake

The applicant submits a license request and supporting information. The application is registered and given an initial status.

## 2. Completeness and eligibility review

The responsible review role checks whether mandatory information is present and whether the request can proceed. Missing or unsuitable submissions leave the main path through a correction, rejection or closure outcome.

## 3. Parallel technical assessment

Relevant specialist reviews can begin once the application passes the initial check. The public model groups these reviews rather than exposing real department or committee names.

## 4. Site inspection and correction

Where an inspection is required, findings are evaluated against the applicable criteria. Corrective work returns to a controlled reinspection loop instead of restarting the entire process.

## 5. Formal decision

Completed reviews are consolidated for a formal decision. Approval and rejection are represented as separate outcomes.

## 6. Issuance or closure

An approved application proceeds to license issuance and notification. Rejected or withdrawn applications close with their own terminal state.

## Important edge cases

- Missing information
- Failed specialist review
- Corrective action after inspection
- Reinspection
- Formal rejection
- Applicant withdrawal
