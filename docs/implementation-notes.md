# From Process Analysis to Implementation

The BPMN model was used to communicate how the municipal license process should behave in the software.

## Analysis outputs used by the team

- Process stages became workflow steps.
- Decision points became transition conditions.
- Role responsibilities informed user permissions and assigned actions.
- Return paths became correction and resubmission flows.
- Inspection outcomes became approval or reinspection transitions.
- Final process outcomes informed application statuses.

## Implementation result

The process was implemented successfully as part of the software product. The model helped preserve the connection between the business workflow and the behavior delivered by the development team.

This repository focuses on the Business Analyst contribution: understanding the operation, resolving process logic and expressing it in a form that could be implemented.
